# SAPIO MORPHEUS Black-Box Challenge

This study evaluates weighted Max-Cut on one CPU core under a fixed deadline. A completed run returns a partition that can be checked by summing the weights of crossing edges.

The frozen panel has 20 graphs and three seeds per graph. The references are BURER2002, PALUBECKIS2004bMST2, an eight-slot MQLib restart portfolio, and the CPU D-Wave TabuSampler. The panel contains 15 newly generated graphs and five graphs from an independent benchmark archive.
